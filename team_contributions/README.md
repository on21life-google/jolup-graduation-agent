# 팀원 제출본과 통합 기준

2026-10-26 받은 우수진·김주미 제출본의 코드·디자인·시험 명세를 보존합니다. 실제 서비스는 저장소 루트의 `app.py`로 실행하세요. 이 폴더의 시안과 미완성 원본은 제품 실행 경로 및 제품 커버리지 측정 범위에 포함하지 않습니다.

루트 `pytest.ini`는 제품 검사 위치를 `tests/`로 명시합니다. 따라서 기본 `python -m pytest -q`가 구현 폴더가 빠진 제출본 시험까지 자동 수집하지 않습니다. 제출 시험의 적용 가능한 기대값은 제품 시험에 별도로 반영했습니다.

| 제출자 | 보존한 자료 | 실제 제품에 통합한 내용 |
|---|---|---|
| 우수진 | 두 HTML 시안, Streamlit 래퍼, 안내문 | 크림·노랑 화면, 검정 테두리·그림자, 토끼 이미지, 대화와 요약의 5:7 배치, 월간 달력·D-day |
| 김주미 | CLI 진입점, 의존성 목록, 두 시험 명세, OpenAI 색인 매니페스트 | 한글 NFC 비교, 문서 종류·조문·파일명 날짜 참고, 원문별 해시·청크 수, 출처 중복 방지 회귀 검사 |

제품의 학점·답변·일정은 기존의 검증된 계산 및 학교 자료를 사용합니다. 시안의 고정 예시(85/130학점·Alex·고정 날짜)를 실제 학생 기록처럼 표시하지 않습니다. [통합 결정과 테스트→코드 안내](../docs/팀원_통합결과.md)에 유지·변환·미적용 이유를 기록했습니다.

## 수진 제출본 보기

`sujin/졸업각site - 복사본 (2).html`은 주 디자인, `sujin/일정표 구현.html`은 달력 아이디어입니다. HTML 안의 데이터와 응답은 디자인 시연용입니다. `UniPath AI.py`는 제출된 절대 Windows 경로만 같은 폴더 경로로 바꾸었습니다. 그 외 HTML·안내문은 원본을 보존했습니다. 제품 토끼 자산은 `assets/sujin/`에 분리했습니다.

## 주미 제출본의 실행 범위

제출 ZIP에 `rag/` 폴더가 없어서 `jumi/main.py`와 원본 시험은 그대로 실행할 수 없습니다. 제공된 테스트는 요구사항의 근거로 읽고, 실행 가능한 통합 검사는 루트 `tests/test_source_metadata.py`를 사용하세요. 이 폴더의 `requirements.txt`는 제출 기록이며 제품 의존성은 루트 `requirements.lock`입니다.

학교 PDF 두 개는 제품 `data/sources/`의 기존 파일과 SHA-256이 동일하여 중복 복사하지 않았습니다. `index_manifest.json`은 제출 당시 134청크·OpenAI `text-embedding-3-small` 색인 기록입니다. 통합 제품은 448청크·로컬 MiniLM을 사용하므로 이 DB 바이너리를 연결하지 않습니다. 임베딩 공간·분할 정책이 다른 캐시를 섞지 않고 제품 모델로 다시 색인합니다. 원본 ZIP은 수정하지 않았습니다. `.DS_Store`와 재생성용 벡터 캐시는 공개 실행 파일에 포함하지 않았습니다.
