## 4. 실제 AI 연결과 ChatGPT 인수 시험

공식 `ChatOpenAI`·`ChatAnthropic` 통합, Pydantic 스키마, `with_structured_output(method="json_schema")`를 사용한다. 앱 설명의 스키마는 **`ExplanationSelection`**이고 의도는 `IntentDecision`이다. 일반 `generate()`의 기본 `ExplanationOutput`과 구분한다. 형식 불일치·거절·미완료는 로컬 계산 결과를 유지하고 허용되지 않은 설명을 표시하지 않는다.

10/25 OpenAI `gpt-4.1-mini` 실제 호출에서 정상·부족·누락 **3종 모두 문장 ID 스키마 통과·계산값 불변·필수 현재/계획 문장 유지**를 확인했고, 새 졸업 질문의 `diagnosis` 분류도 확인했다. 원본은 `reports/fact_selection_live_validation_20261025.json`이다. 키·학생 원문·생성 문장을 이 보고서에 저장하지 않았다. **Anthropic은 공식 통합과 모의 전송 시험이며 실제 계정 호출은 미검증**이다.

10/25 ChatGPT 새 대화에서도 **수정 프롬프트 v2의 정상·부족·누락 3사례가 핵심 인수 기준을 통과했다.** 기대 정답표는 보내지 않고 제공 자료와 CSV에서 계산하게 했다. 네 요소, 손계산 일치, 현재/전망 구분, 누락값 비추정, 정확한 첨부 파일명, 등록일의 확인/미확인 구분, 미래 개설 미보장을 각각 확인했다. 표시 모델은 `Pro`이며 내부 모델 ID는 UI에서 확인되지 않았다.

첫 누락 사례에서는 ① 필수 입력 누락 시 종합판정을 확인 필요로 우선 표시하는 프로젝트 정책 ② meta의 정확한 파일명 표기가 실패했다. 학교 규정과 프로젝트 표시 정책을 분리해 명시하고 파일명과 문서 제목을 구분하도록 수정한 뒤 **세 사례 모두 새 대화로 재시험**했다. 원본 실패와 v2 응답·해시는 `reports/chatgpt_acceptance_20261025.json`에 남겼고 요약 시 응답 파일 해시를 다시 대조했다. **이 시험은 구현 후 인수 확인이며, 원래 계획한 ‘구현 전에 검증 통과’ 절차를 과거에 지켰다는 증거로 바꾸지 않는다.** 모든 문장·미래 입력의 정확성이나 독립 미공개 평가셋 통과를 뜻하지 않는다.

LangSmith는 10/23 정상 더미의 명시적 전송과 웹 저장 내용을 실제 확인했다(`reports/langsmith_live_validation.json`). 현재 전체 시험은 관찰·허용 요약·전송 계약을 검사하며 이번 문서 정리에서 외부 LangSmith 재전송을 새로 수행했다고 표시하지 않는다.
