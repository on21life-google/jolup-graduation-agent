## 3. 검색 청크와 근거

2026-10-23의 개선 후 실제 캐시 모델·Chroma 재색인 결과를 유지하고, 최신 전체 시험에서도 실제 벡터 경로를 검사했다. 이번 통합의 7문서·448청크를 다시 확인했으며 최대128토큰·초과0이었다. NFC 비교는 인용 원문을 변경하지 않는다. 문서 종류·조문·파일명 날짜 힌트와 문서별 해시·청크 수를 추가했다.

| 구분 | 실측 | 해석 |
|---|---:|---|
| 원문 입력 잘림 | **0/448개 청크** | 이전 178/208개에서 개선. 특수 토큰 포함 최대 128토큰 |
| 기존 질문의 기대 출처·페이지 hit@5 | **17/20** | 이전과 같은 수치. 잘림 해소를 검색 점수 상승으로 설명하지 않음 |
| 추가 표현 질문 hit@5 | **11/12** | 같은 주제의 표현 변형이며 외부 독립 평가셋은 아님 |
| 기존 답변의 숫자·조건·출처 기대 검사 | **20/20** | 검색 상위 밖의 검토된 원문 문맥 보완 포함 |

검색 발췌 `text`와 전체 페이지 `context_text`를 함께 제공해 같은 페이지의 표 머리글·예외를 읽게 한다. 여러 페이지 표의 의미를 자동 복원하는 기능은 아니다. 검색 밖에서 보완한 인용은 `citation_origin=source_context`로 구별한다. 어휘 대체 모드를 벡터 성공으로 표시하지 않는다. [청크 점검](청크_품질점검.md)과 [실측 JSON](quality/청크_실측요약.json)에 정책·해시·한계가 있다.

## 4. 실제 AI 연결과 ChatGPT 인수 시험

공식 `ChatOpenAI`·`ChatAnthropic` 통합, Pydantic 스키마, `with_structured_output(method="json_schema")`를 사용한다. 앱 설명의 스키마는 **`ExplanationSelection`**이고 의도는 `IntentDecision`이다. 일반 `generate()`의 기본 `ExplanationOutput`과 구분한다. 형식 불일치·거절·미완료는 로컬 계산 결과를 유지하고 허용되지 않은 설명을 표시하지 않는다.

10/25 OpenAI `gpt-4.1-mini` 실제 호출에서 정상·부족·누락 **3종 모두 문장 ID 스키마 통과·계산값 불변·필수 현재/계획 문장 유지**를 확인했고, 새 졸업 질문의 `diagnosis` 분류도 확인했다. 원본은 `reports/fact_selection_live_validation_20261025.json`이다. 키·학생 원문·생성 문장을 이 보고서에 저장하지 않았다. **Anthropic은 공식 통합과 모의 전송 시험이며 실제 계정 호출은 미검증**이다.

10/25 ChatGPT 새 대화에서도 **수정 프롬프트 v2의 정상·부족·누락 3사례가 핵심 인수 기준을 통과했다.** 기대 정답표는 보내지 않고 제공 자료와 CSV에서 계산하게 했다. 네 요소, 손계산 일치, 현재/전망 구분, 누락값 비추정, 정확한 첨부 파일명, 등록일의 확인/미확인 구분, 미래 개설 미보장을 각각 확인했다. 표시 모델은 `Pro`이며 내부 모델 ID는 UI에서 확인되지 않았다.

첫 누락 사례에서는 ① 필수 입력 누락 시 종합판정을 확인 필요로 우선 표시하는 프로젝트 정책 ② meta의 정확한 파일명 표기가 실패했다. 학교 규정과 프로젝트 표시 정책을 분리해 명시하고 파일명과 문서 제목을 구분하도록 수정한 뒤 **세 사례 모두 새 대화로 재시험**했다. 원본 실패와 v2 응답·해시는 `reports/chatgpt_acceptance_20261025.json`에 남겼고 요약 시 응답 파일 해시를 다시 대조했다. **이 시험은 구현 후 인수 확인이며, 원래 계획한 ‘구현 전에 검증 통과’ 절차를 과거에 지켰다는 증거로 바꾸지 않는다.** 모든 문장·미래 입력의 정확성이나 독립 미공개 평가셋 통과를 뜻하지 않는다.

LangSmith는 10/23 정상 더미의 명시적 전송과 웹 저장 내용을 실제 확인했다(`reports/langsmith_live_validation.json`). 현재 전체 시험은 관찰·허용 요약·전송 계약을 검사하며 이번 문서 정리에서 외부 LangSmith 재전송을 새로 수행했다고 표시하지 않는다.

요구 추적 수치는 [requirements.json](tdd/requirements.json)의 현재 항목을 집계했다. 연결 존재 확인이 모든 인수 조건의 증명은 아니다. TDD 재구성 실습의 근거는 `reports/tdd_study/20261026_015458_005907/summary.json`이다. [로컬 함수 분석](APPMAP.md)은 선택한 코어 파일·호출 스레드의 관찰이며 전체 앱의 시간순 기록이 아니다. AppMap 패키지는 설치하지 않았다.

`POST /chat`은 `agent.respond()`의 LangGraph를 실행하며 `invoke(version="v2").value` 결과를 반환한다. 혼합 질문은 필요한 분야를 순차 실행하고, 서버 세션의 최근4턴 결과는 입력과 학교 자료가 같은 명시적 재요청에서 재사용한다. `/diagnosis`·`/plans`·`/regulations` 등 분야별 API는 `call_domain()`으로 위임한다. **HTTP 채팅은 외부 LLM 호출과 LangSmith 전송을 지원하지 않는다.** 로컬 모드의 명시적 AI 연결·선택한 더미 기록 전송은 유지한다. [API 실습](API_EXPLORER.md), [개발도구 학습지도](개발도구_학습지도.md), [실습 코드 비교](실습코드_비교보고서.md)에 경계와 선택 이유가 있다.
