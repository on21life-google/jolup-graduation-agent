# 교수 수업자료와 현재 구현의 대조

검토일: 2026-10-26. 제공된 이론 자료와 **실습 ZIP 9개**를 읽고 현재 코드와 대조했다. 이론 PDF는 제목 기준 8종이며, 단독 제공본과 ZIP 배포본의 Day4·Day5가 서로 달라 **10개 파일 버전·351쪽**을 구분했다. 기획·결과 발표 양식은 16장·14장이다. 실습 코드는 읽기 전용으로 분석했으며 노트북 출력·키·실제 계정 실행을 검증 근거로 사용하지 않았다. [실습 코드 비교보고서](실습코드_비교보고서.md)에 버전·함수·셀과 변경 이유를 정리했다. 수업 코드를 모두 복제했거나 수업 코드보다 보편적으로 우수하다는 판정은 아니다.

현재 프로젝트는 **학사 계산·근거 검색·조건부 계획·일정 파일 생성**에 집중한다. 수업 기술을 제외한 이유는 설명할 수 있지만, 그 이유를 적는 것만으로 수업의 구현 목표를 충족한 것으로 바꾸지는 않는다. 최신 시험과 실제 실행 여부는 [검증 기록](검증결과.md)을 따른다.

## 자료를 읽는 기준

| 표기 | 뜻 |
|---|---|
| 반영 | 해당 동작을 코드에서 확인했다. 실제 서비스 검증 여부는 별도로 적는다. |
| 부분 반영 | 일부 개념·기능은 있지만 수업이 다루는 동작 전체를 구현하지 않았다. |
| 다른 방식 선택 | 같은 목적을 다른 방법으로 해결했다. 대안과 제한을 설명한다. |
| 제외 | 현재 요구와 연결되지 않아 추가하지 않았다. 재검토 조건을 적는다. |
| 확인 대기 | 필요한 코드·실측·팀 자료가 없어 결론을 내리지 않았다. |

문서 속 설치·실행·Notion 제출 안내는 학습 자료다. 임의 설치·외부 게시의 권한으로 취급하지 않는다. 사용자가 정한 GitHub 없는 로컬 통합, Windows 검증·시연 영상 제외, 보안·성능 목표 확장 제외를 유지한다.

## 제외한 기술과 다시 검토할 조건

| 기술 | 이번에 넣지 않은 이유 | 다시 필요해지는 조건 |
|---|---|---|
| 일반 SQL 업무 DB·SQLAlchemy | 현재는 가상 CSV/JSON 입력을 읽어 계산한다. 지속적인 학생 CRUD·관계 조회가 없다. Chroma 내부의 SQLite 파일은 별도 학사 DB와 다르다. | 학생 기록·정정 이력·여러 사용자 편집을 영속 보관해야 할 때 관계형 모델을 비교한다. |
| MongoDB 등 별도 NoSQL | 파일을 쓴다는 사실만으로 NoSQL DB를 도입한 것은 아니다. 별도 문서 쓰기·조회 요구가 없다. | 가변 문서를 지속 저장하고 쿼리해야 하는 실제 패턴이 생길 때 비교한다. |
| Redis | local 앱 메모리 또는 단일 FastAPI 프로세스의 최대64개 메모리 세션을 사용한다. 서버 재시작·LRU 축출 시 사라지며 공유 세션·작업 큐는 없다. | 여러 프로세스가 상태·작업을 공유해야 할 때 검토한다. 메모리 기능을 위해 Redis부터 설치하지 않는다. |
| Supervisor·여러 자율 에이전트·Reflection | 역할별 Python 모듈과 정해진 워크플로우로 현재 범위를 설명할 수 있다. 별도 모델 감독·재평가가 필요한 과제를 정의하지 않았다. | 단일 경로로 해결하기 어려운 독립 작업·검증 기준이 생길 때, 종료 조건과 재시도 한도를 먼저 설계한다. |
| 병렬 fan-out·reducer·스트리밍 | 현재 필요한 여러 분야를 정해진 순서로 실행한다. 병렬 상태 합치기나 점진 출력은 구현하지 않았다. D4B p17도 완전 병렬을 심화 범위로 구분한다. | 독립 작업을 함께 실행하거나 부분 응답 표시가 필요해지면 검토한다. 혼합 질문을 처리하기 위해 반드시 병렬화해야 하는 것은 아니다. |
| 장기 프로필/에피소드 Store·영구 checkpoint | 현재 세션 밖 기억이 요구되지 않는다. D4 p24도 장기 메모리는 개념 이해와 구현 범위를 구분한다. | 세션이 끝나도 학생별 작업을 이어야 하거나 승인 중단 후 복구가 필요할 때 검토한다. |
| LangGraph `interrupt`·`thread_id`·`context_schema` | 요청 안에서 종료하는 그래프와 일반 컨텍스트를 사용한다. ICS의 화면 승인은 있지만 그래프 중단·재개는 없다. | 현재 HTTP 세션 ID와 메모리 보관은 자체 계약이며 LangGraph checkpoint의 thread_id와 다르다. 중단된 그래프 복구·실행 컨텍스트 계약이 필요할 때 도입한다. UI 승인 구현을 LangGraph HITL 전체 구현으로 표현하지 않는다. |
| 일반 대화·피드백DB·임의 규정문서 업로드 | 인사도 현재 서비스 범위 안내로 답한다. 고정 학교 근거와 가상 학생 입력이 대상이다. CSV 성적표 업로드는 RAG 문서 업로드와 다르다. | 인사는 짧은 로컬 응답으로 개선할 수 있다. 문서 범위 확대·피드백 저장은 해당 사용 요구와 근거 검토 절차가 정해지면 추가한다. |
| HR 조직·연차·휴가 DB와 동일 도구 | 수업의 업무 예시를 졸업요건·성적·학사일정으로 바꿨다. 도구 원리의 적용과 HR 기능 복제는 다르다. | 학사 도메인에 실제 교무 시스템 연동 요구가 생길 때 적절한 인터페이스를 설계한다. |
| 클라우드 배포·추가 운영 서비스 | 팀의 현재 전달 방식은 로컬 통합과 로컬 시연이다. Docker 제공과 클라우드 배포 완료를 구분한다. | 팀 외부 사용자가 상시 접속해야 하는 요구가 확정되면 검토한다. |
| Windows 시험·시연 영상·새 보안/성능 도구 | 사용자가 이번 범위에서 명시적으로 제외했다. | 별도 요청이 있을 때만 범위를 다시 정한다. |

## 코드 대조와 검증의 범위

일자별 코드·노트북 소스 셀·안내·의존성 파일을 읽었다. 중복 ZIP은 SHA로 식별했고 공급자·SDK 버전 차이를 개념 차이와 분리했다. 설치·실제 모델 호출·외부 게시 안내는 실행하지 않았다. 따라서 교수 예제와 프로젝트를 같은 실제 계정·자료로 실행한 성능·정답률 경쟁 실험은 아니다.

| 비교 축 | 확인한 결과 | 남은 제한 |
|---|---|---|
| 요구와 기대 결과 | 단일·혼합·명시적 재요청·누락·도구 실패를 코드와 시험으로 연결 | 무한한 자연어 질문의 정확성 증명은 아님 |
| 실행 경로 | 필요한 분야·합성·재사용·종료를 LangGraph와 로컬 trace에서 확인 | 자율 ReAct와 반복 재검색은 없음 |
| 메모리 | 4턴, 이전 검증 결과 재사용, 학생/성적/학교 자료 변경 시 무효화 | 전체 대화의 LLM 맥락 이해·영구 기억은 없음 |
| 검색과 출처 | 토큰 한도·페이지 문맥·독립 기대 출처를 구분 | 교수 모델·Qdrant와 동일 자료 A/B 비교는 하지 않음 |
| 복잡성과 분석 | 책임별 함수·타입 계약·실행 기록·테스트→코드 문서. 10/26 같은 동결본 Sonar의 S3776 0건·coverage100% | 전체 Gate는 ERROR: 새 지적12건(반복 리터럴7·응답 문서5). 열린 전체39건을 복잡도0과 구분. [최신 분석](SONARQUBE.md) |
| 실행 구성 | local/HTTP 채팅 계약·Compose 4서비스 설정 | 최신 Docker 새 이미지 실제 통합은 환경 문제로 미검증 |

자료를 받아 대조한 것은 완료했고, 실제 실행 여부는 소스 버전과 연결된 시험만 근거로 한다. 현재까지의 차이와 미적용 이유를 [실습 코드 비교보고서](실습코드_비교보고서.md)에 남겼다. 팀원 산출물 통합은 별도 자료 대기다.

## 최종 발표자료로 연결

현재17장 파일은 기획안 수정본이다. 새14장 양식은 **실제 성과·실패·배운 점·향후 과제**를 담는 결과 발표자료이므로 별도로 완성한다. [슬라이드별 작성안](발표자료_작성안.md)에 넣을 내용과 근거를 정리했다.

미적용 기술은 본문8장의 설계 결정에 중요한 차이만 요약하고, 전체 대조표는 README 링크로 연결한다. 11장에는 목표와 실측을, 12장에는 실패와 제한을 넣는다. 팀원 담당 배정을 실제 완료 기여로 바꾸지 않는다. 실습 대조와 최종 PPT 제작·렌더 검증도 각각의 완료 증거로 구분한다.
