# 결과 발표 읽기자료 — 졸업각, 14장

2026-10-26 기준, 교수님의 14장 결과 발표 양식에 작성한 팀원 통합 PPT와 발표자 노트를 따라 읽는 원고다. 제공된 수업 이론·실습 코드의 대조와 필요한 구현 보완은 마쳤다. **10/26 수진·주미 제출본을 받아 통합했다. 제출물의 실제 기여와 AI 통합 재구현을 구분한다.** 이 문서의 갱신 자체가 PPT 렌더링·최종 검토의 완료를 뜻하지 않는다.

발표 일정은 사용자가 정한 **2026-10-26 오전**을 따른다. 강의계획의 같은 날 오후·15분 발표+10분 Q&A와 결과 양식의 표지 노트 10분, 장별 권장시간 합계 17분 30초가 서로 다르다. **본문 10분과 선택 설명 5분**을 준비하고 Q&A는 별도로 둔다. 아래 1~13장 시간 합계는 600초이며 실제 배정시간에 맞춰 선택 설명을 사용한다.

**슬라이드에서 볼 곳:** 제목 ‘졸업각’, 부제, 5조·팀원·발표일.

## 6. 시스템 구성도 — 60초

**슬라이드에서 볼 곳:** UI·API, Agent, 선택 LLM, 도구와 지식 저장소의 연결.

> 로컬 모드에서는 Streamlit이 에이전트를 직접 실행합니다. HTTP 모드에서는 FastAPI의 `/chat`을 거쳐 에이전트와 MCP 도구, Chroma에 연결합니다. Docker Compose도 app, api, mcp, chroma의 4서비스로 구성했습니다. 학사 계산은 Python 코드가 결정하고, 선택한 외부 API 기반 LLM은 공식 LangChain 통합으로 호출합니다. 실제 OpenAI 검증에 사용한 모델은 gpt-4.1-mini입니다. 규정 임베딩은 별도로 로컬 다국어 MiniLM을 사용합니다. HTTP 모드는 AI 설명과 LangSmith 전송을 끄고 실행 단계만 열람하며, 최신 Docker 실제 기동은 재검증 대기입니다.

발표자 참고: gpt-4.1-mini는 **실제 검증 모델**이고 코드 기본값 gpt-6-luna와 다르다. 로컬 모드는 사용자가 연결한 경우 AI 설명·LangSmith를 사용할 수 있다. HTTP 요청에 모델 키를 실어 보내지 않는다. 클라우드 배포는 하지 않았다. Chroma 내부 SQLite 저장파일을 별도의 학생 학적 SQL DB로 운영하는 것은 아니다.

근거: [Compose](../compose.yaml), [채팅 클라이언트](../jolup/chat_client.py), [FastAPI](../jolup/study_api.py), [에이전트](../jolup/agent.py), [프로젝트 구조도](프로젝트_구조도.md).

## 7. 에이전트 처리 흐름 — 60초

**슬라이드에서 볼 곳:** 단일·복합 의도, 규정 → 학사 계산 → 일정, 결과 합성과 실행 한도.

> 질문과 가상 기록을 받아 단일 요청인지 복합 요청인지 나눕니다. 복합 질문은 규정, 학사 계산, 일정의 순서로 필요한 분야를 최대 세 개 실행한 뒤 합성합니다. 수강 계획에는 현재 진단이 포함되므로 진단 그래프 노드를 따로 중복 실행하지 않습니다. 실패한 부분은 다른 결과와 구분해 표시하고 누락이나 충돌은 확인 필요로 답합니다. 최근 네 번의 결과는 같은 학생·성적표·학교 자료에서 명시적으로 다시 요청할 때만 재사용합니다. 입력이나 근거가 바뀌면 저장 결과를 폐기합니다.

발표자 참고: 중복 **그래프 노드**를 없앤 것이며, 계획 함수 안의 재검증까지 포함해 계산이 정확히 한 번이라고 단정하지 않는다. 이 구현은 LangGraph로 상태와 분기를 표현한 제한된 워크플로다. 수업의 ‘도구 결과 관찰 후 다음 행동을 다시 선택하는 자율 ReAct 반복’과 다르며, ReAct를 구현했다고 말하지 않는다. `version="v2"` 결과의 `.value` 처리와 메모리 경계가 실제 코드·시험에 반영돼 있다.

근거: [에이전트](../jolup/agent.py), [계획 계산](../jolup/planner.py), [4턴 메모리](../jolup/conversation.py), [혼합·메모리 시험](../tests/test_agent_conversation.py).

## 8. 구성요소와 설계 결정 — 40초

**슬라이드에서 볼 곳:** 구성요소 표의 ‘설계 결정과 이유’, 하단의 수업과 다른 선택.

> 도구 이름을 많이 넣기보다 현재 요구에 필요한 이유를 정리했습니다. 계산과 설명을 분리하기 위해 LangGraph와 LangChain을 사용하고, 공개 문서의 작은 로컬 색인은 Chroma와 MiniLM을 사용합니다. MCP의 아홉 도구는 계산·검색·승인 후 ICS 생성을 같은 계약으로 제공합니다. 메모리는 최근 네 턴, API는 최대 64개 임시 세션입니다. 영구 학생 이력이나 여러 서버의 세션 공유 요구가 없어 별도 SQL과 Redis는 넣지 않았습니다.

발표자 참고: 수업 Day3의 Qdrant/FastEmbed와 선택 심화 Dense+BM25/RRF를 그대로 사용한 것은 아니다. 제품 검색은 **어휘 점수 0.55 + 벡터 점수 0.45 및 출처·주제 보정**이며 BM25나 RRF로 소개하지 않는다. 로컬 MiniLM 임베딩과 외부 OpenAI 생성 API는 별개다. 성능 우위를 비교 입증했다는 주장은 하지 않는다. Cross-Encoder는 수업의 구조 소개 범위, SQLite는 Day2 선택 심화다. 자율 ReAct·영구 체크포인트·클라우드 배포를 미적용한 이유도 설명하되, 그 선택만으로 해당 수업 학습 목표를 구현 완료했다고 말하지 않는다.

근거: [수업자료 대조표](수업자료_반영대조표.md), [실습 코드 비교보고서](실습코드_비교보고서.md), [아키텍처 의사결정](아키텍처_의사결정.md), [검색 코드](../jolup/rag.py).

## 9. 핵심 구현: 검증된 사실만 선택하는 AI 설명 — 80초

**슬라이드에서 볼 곳:** `explain_result`의 사실 ID 검사와 필수 사실 병합 코드 발췌.

> 핵심은 모델이 학점이나 판정을 새로 작성하게 하지 않는 것입니다. 먼저 계산 코드가 학점, 현재 상태와 조건을 정해 사실 목록을 만듭니다. 모델은 그 사실의 ID만 선택합니다. 공식 LangChain의 구조화 출력과 Pydantic으로 응답 형식을 검사하고, 허용된 목록에 없는 ID는 거절합니다. 이후 필수 사실과 선택한 사실을 합쳐 코드에 있는 문장으로 답변을 조립합니다. 따라서 모델이 새로운 숫자나 URL을 만들지 않고, 현재 미충족이나 조건부라는 주의 문장도 빠지지 않게 합니다. 화면 코드는 이 검증과 병합 부분의 축약 발췌입니다. OpenAI 실제 호출에서 세 사례와 의도 분류를 검증했고, Claude 실제 계정 연결은 아직 검증하지 않았습니다.

발표자 참고: 구조화 출력이 모든 답변의 정확성을 자동 보장하는 것은 아니다. 사실 목록과 학사 계산 자체는 정답표·원문·회귀 시험으로 별도 확인해야 한다. 공식 SDK의 모의 HTTP 계약 시험과 실제 계정 호출을 구별한다. 이전 작성안의 9장 ‘청크와 원문 문맥’ 대신 현재 PPT의 **사실 선택 구현**을 설명하며 청킹 질문은 8장 선택 설명이나 Q&A에서 답한다.

근거: [AI 설명 코드](../jolup/llm.py), [사실 계약 시험](../tests/test_explanation_facts.py), [실제 모델 검증 기록 · 공개 요약](검증결과.md).

## 10. 정상·부족·누락 데모 — 60초

**슬라이드에서 볼 곳:** 세 사례의 현재 이수, 목표 전망, 답변 핵심을 비교한 편집 가능한 표.

> 같은 질문을 세 사례에 넣어 비교합니다. 정상 준비 사례는 현재 90학점이며, 수강 중 15학점과 향후 9학점씩을 이행하면 123학점이라는 조건부 계획입니다. 부족 사례는 현재 38학점입니다. 현재 수강 15학점과 남은 두 정규학기 18학점씩을 모두 이행해도 89학점이므로, 그 계획에서는 34학점이 부족합니다. 계절학기나 초과학점은 이 계산에 포함하지 않았습니다. 자료 누락 사례는 확인된 90학점은 유지하지만 채플 기록이 없어 현재와 목표의 종합판정을 모두 확인 필요로 표시합니다.

| 사례 | 현재 확정 이수 | 현재 수강을 통과하면 | 목표까지 제시한 계획 | 판정에서 강조할 점 |
|---|---:|---:|---|---|
| 정상 준비 | 90 / 123 | 105 | 90 + 15 + 9 + 9 = 123 | 현재 미충족 / 목표 조건부 가능 |
| 학점 부족 | 38 / 123 | 53 | 38 + 15 + 18 + 18 = 89 | 해당 계획에서 34 부족. 현재 확정 이수만의 부족분은 85 |
| 자료 누락 | 90 확인 | 수강 중 이수는 별도 | 누락된 조건 때문에 확정하지 않음 | 채플 미확인 / 현재·목표 확인 필요 |
