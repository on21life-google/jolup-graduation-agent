# 졸업각 · 나 졸업 괜찮아?

가상 성적표를 읽어 현재 졸업요건과 목표 졸업까지의 수강 계획을 구분하고, 학교 근거와 학사일정을 함께 보여 주는 로컬 앱입니다. **성결대학교 2024학번 컴퓨터공학과·전공심화·공학인증 제외**를 대상으로 합니다. 기본 학생은 2026년 3학년 2학기 재학 중인 가상 인물 김가온입니다.

## 시작하기 · 팀 공유 순서

공개 저장소는 [on21life-google/jolup-graduation-agent](https://github.com/on21life-google/jolup-graduation-agent)입니다. Git을 몰라도 저장소의 **Code → Download ZIP**을 눌러 내려받고 압축을 풀면 됩니다. 이 저장소는 코드·자료를 공유하는 곳이며 실행 중인 웹앱을 호스팅하지 않습니다.

1. [최종 발표자료 14장](artifacts/jolup-presentation-20261026.pptx)을 내려받아 전체 목표·구현·검증 결과를 확인합니다.
2. [전체 다이어그램 HTML](artifacts/diagrams.html)을 내려받은 뒤 브라우저로 엽니다. GitHub 파일 화면에서는 HTML이 실행되지 않습니다. 처음 열 때 Mermaid CDN을 불러올 인터넷 연결이 필요하며, 라이브러리가 캐시되지 않은 환경에서도 인터넷이 필요합니다.
3. [파일 트리와 시스템 구성](docs/프로젝트_구조도.md) → [테스트부터 읽는 학습 가이드](docs/TDD_학습가이드.md) 순서로 읽고 아래 명령으로 앱을 실행합니다.
4. 담당 코드를 검토한 뒤 [모듈 인터페이스](docs/INTERFACES.md)에 맞춰 팀원 파일을 전달하고 로컬에서 통합합니다. GitHub 사용법을 익히는 것이 참여 조건은 아닙니다.

**Python 3.12**를 설치하고 압축을 푼 프로젝트 루트에서 다음 명령을 실행합니다. 의존성 설치와 최초 임베딩 모델 다운로드에는 인터넷 연결이 필요합니다.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python scripts/build_index.py
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다. **API 키 없이** 더미 학생의 졸업요건 계산·벡터 검색·수강 계획·일정 파일 생성을 이용할 수 있습니다. 선택적 생성AI나 LangSmith를 실제로 호출할 때만 **각자 발급받은 해당 서비스의 키**를 앱 또는 로컬 설정에 입력합니다. 실제 키는 저장소·팀 공유 ZIP·채팅에 올리지 마세요.

공개본에는 코드·공개 학교 자료·가상 학생 자료·학습 문서를 담았습니다. **교수님 원본 자료, 실제 API 키, 개인 학적·성적 자료, 비공개 대화 원본은 포함하지 않습니다.** 상세 실행 기록은 원래 작업 폴더에 보관하고 공개본에는 [검증 결과](docs/검증결과.md)와 공유용 요약을 제공합니다.

Mac은 `scripts/run.command`로 시작할 수 있습니다. Windows 검증은 팀 합의로 이번 범위에서 제외했습니다. Docker Desktop이 실행 중이면 `docker compose up --build`로 앱·Agent API·MCP·Chroma의 4서비스를 함께 실행하도록 구성했습니다. 최신 새 이미지 실제 기동은 환경 문제로 미검증이며 검증 기록을 확인하세요. 자세한 방법은 [실행 안내](docs/RUN.md)를 확인하세요.

## 팀 역할과 코드

아래는 담당 배분과 학습 범위입니다. 팀원 산출물은 아직 통합하지 않았으므로 실제 완료 기여를 뜻하지 않으며, AI가 작성한 코드를 해당 팀원이 직접 작성한 것으로 표시하지 않습니다.

| 담당 계획 | 맡은 범위 | 먼저 읽을 파일 |
|---|---|---|
| **윤석현** | **성적표 파싱, 학점 인정, 졸업요건 비교, 학기별 수강 계획** | `jolup/academic.py`, `jolup/planner.py`, `jolup/course_solver.py` |
| 김주미 | 원문 파싱, 페이지·토큰 한도를 지키는 청킹, 다국어 임베딩, Chroma 검색, 출처 검증 | `jolup/rag.py`, `jolup/chunking.py`, `data/sources.json` |
| 우수진 | LangGraph 분기, Streamlit, MCP 연결, 일정 미리보기·승인·ICS | `app.py`, `jolup/agent.py`, `jolup/calendar.py`, `jolup/mcp_client.py`, `jolup/mcp_server.py` |

[윤석현 계산 로직 설명](docs/윤석현_계산로직_설명.md)에는 손계산 예제, 함수별 입력·출력, 오류 확인 방법, 발표 질문을 정리했습니다. [모듈 인터페이스](docs/INTERFACES.md)를 지키면 GitHub 없이 담당 파일을 받아 로컬에서 합칠 수 있습니다.

## 화면에서 확인할 것

1. **현재 졸업요건**: 확정 이수만 합산합니다. 수강 중·계획·철회·F는 현재 취득 학점에서 제외합니다.
2. **목표 졸업까지 준비 상태**: 현재 수강 과목의 합격, 미래 후보의 실제 개설과 합격, 등록·채플·작품 심사 완료라는 조건을 별도로 표시합니다.
3. **reason 표**: 영역 / 필요 / 이수 / 부족. 총학점뿐 아니라 필수과목과 비학점 요건도 확인합니다.
4. **근거·meta**: 파일명, PDF 페이지, 공식 주소, 등록일. 등록일을 모르면 미확인으로 둡니다.
5. **계산 과정**: 과목별 인정·제외 이유를 표시합니다. LLM의 내부 추론이 아니라 계산 코드의 기록입니다.
6. **일정**: 학교 자료의 날짜를 미리 보고 승인해야 ICS 다운로드를 생성합니다.

공식 학적부·증명서를 발급하거나 성적을 변경하지 않습니다. 제공하는 프로필·성적표는 전부 더미이고 학교의 최종 졸업사정과 구분합니다.

## API 키만 바꾸는 AI 연결

**local 대화 모드**에서 화면의 **AI 설명 연결 · 선택**에서 키를 입력하고 **대화 답변에 AI 설명 추가**를 켭니다. 알려진 키 접두사는 Claude/OpenAI를 자동 인식하며, 불명확할 때만 서비스를 선택합니다. 화면 모델 입력과 `JOLUP_LLM_MODEL`을 비우면 서비스별 기본 모델을 사용합니다. `jolup/llm.py`는 설정과 개인정보·오류 경계를 관리하고, 실제 모델 요청·응답 변환은 공식 LangChain `ChatOpenAI`·`ChatAnthropic` 통합에 맡깁니다. 계산·화면 코드를 바꿀 필요가 없으며 키 입력만으로 호출하지 않습니다.

`JOLUP_AGENT_API_URL`이 설정되면 채팅은 FastAPI `/chat`으로 연결됩니다. 이 HTTP 모드는 API 키를 전달하지 않고 생성AI를 끕니다. Docker Compose의 기본 채팅도 이 경로입니다. Python 직접 실행에서 해당 변수를 비우면 기존 local 모드와 선택적 AI를 이용합니다. 서버는 최대64개 세션에 각각 최근4턴 결과를 보관하며 재시작·LRU 축출 시 사라집니다.

local 모드에서 API 사용을 켠 질문에는 최대 두 AI 단계가 실행됩니다. `classify_intent`는 미리 정한 졸업·수강·일정 어휘와 이전 의도 유형만 보내 경로를 분류합니다. 계산·검색 후 `explain_result`는 집계·진단표·학교 근거로 별도 설명을 만듭니다. **학점 계산과 판정표는 Python 결과를 유지**하며 질문 원문·대화 전체·성적표 원문·이름·학번을 보내지 않습니다. 실패한 AI 단계는 로컬 처리로 이어가고 상태를 표시합니다. 실제 키는 채팅이나 팀 전달 ZIP에 넣지 마세요. [API 설정·오류 처리](docs/API.md)

현재 앱은 `ExplanationSelection`·`IntentDecision`이라는 Pydantic 출력 계약을 `with_structured_output(..., method="json_schema")`로 전달합니다. AI 설명 단계는 계산 결과로 만든 **문장 ID만 선택**하고, 화면 문장은 로컬에서 조립합니다. 현재 판정·수강 중 학점·목표 조건·확인 필요 경고는 모델이 빼도 유지됩니다. 새 숫자나 졸업 보장을 자유롭게 덧붙이지 못하도록 한 대신 표현의 자유도를 줄인 선택입니다. 구조 불일치·거절·미완료·연결 실패는 로컬 결과로 이어집니다. 이 제약도 학교 규정 해석과 입력 자료 자체의 정확성을 증명하지는 않습니다.

OpenAI의 실제 API 시험과 모의 HTTP 계약 시험은 구분해 [검증 결과](docs/검증결과.md)에 기록합니다. 과거 `ExplanationOutput` 실호출을 새 문장 선택 계약의 검증으로 재사용하지 않습니다. **Claude 실응답은 미검증**이며 두 공급자의 요청·오류 계약은 공식 통합 코드와 SDK를 실행하고 HTTP 경계만 모의 처리해 검사합니다. 키가 없거나 AI 사용을 끄면 로컬 분류·계산·검색 모드입니다. Claude의 단일 워크스페이스 키는 키만으로 연결하고, 조직 전체 키는 선택 항목인 워크스페이스 ID도 입력합니다.

기본 모델 접근 오류가 나면 **사용 가능한 모델 확인**을 누르고 허용된 텍스트 모델 ID를 입력합니다. 같은 회사 키를 바꾸면 모델을 유지하고, 다른 회사로 바꾸면 그 회사에 저장해 둔 모델을 복원합니다. 계정에 지정 모델의 권한이 없으면 목록에서 한 번 다시 선택해야 합니다.

## 계산 기준과 자료 한계

총 123학점, 교필 14, 교선 20, 전공 합계 63(주전공 42 + 심화 21), 필수 설계 2과목, 채플 6학기, 등록 8학기, 졸업작품 심사를 확인합니다. `기타 26`을 일선 필수 26학점으로 만들지 않습니다. 예전 전필의 초과 학점도 전공 합계에 인정합니다.

남은 학기 전체를 함께 탐색해 중복 이수·필수과목·과목 순서·학기 및 연간 한도를 검사합니다. 제공 안내문에 따라 4학년은 기본 9~18학점, 1~3학년은 15~18학점, 연간 기본 36학점을 적용합니다. 예외·초과 이수는 승인 정보 없이 자동 적용하지 않습니다.

미래 실제 강의시간표와 여석은 제공되지 않았습니다. 추천은 공식 교육과정상의 **후보**이며 시간 충돌과 수강 가능 여부는 확인 필요입니다. 편입 등 지원 범위를 벗어나는 조건이나 자료 누락은 판정을 보류합니다. 검토된 원문 또는 규칙이 변경되면 원문 대조를 다시 해야 계산 판정을 확정합니다.

## 코드를 이해하기 위한 실행 기록

[Swagger·Postman 실습](docs/API_EXPLORER.md)은 같은 계산 함수를 HTTP 요청·응답으로 읽는 입구입니다. `python -m jolup.study_api` 실행 후 `http://127.0.0.1:8001/docs`를 열고, Postman 컬렉션으로 정상·부족·누락 사례를 반복할 수 있습니다. [개발도구 학습지도](docs/개발도구_학습지도.md)는 Lang 계열 도구·프레임워크·프로세스 관리의 실제 역할을 구분합니다. [AppMap 검토와 cProfile 실습](docs/APPMAP.md)에서는 추가 서비스 없이 내장 더미의 함수 호출과 시간을 분석합니다.

[전체 파일 트리와 시스템 구성도](docs/프로젝트_구조도.md)는 실제 파일 위치, 모듈 연결, API 키가 필요한 경계를 보여줍니다. [전체 아키텍처와 의사결정](docs/아키텍처_의사결정.md)은 외부 LLM·로컬 임베딩·Chroma·청크·MCP·Docker를 각각 왜 사용하는지, 어떤 대안과 검증 한계가 있는지 설명합니다. 구성도와 색인·질의 순서도를 먼저 보고 아래 테스트·코드 학습 자료로 이어갈 수 있습니다.

명시적으로 “아까 그 규정 다시 보여줘”처럼 요청하면 최근 검증 결과를 재사용합니다. 학생·성적표·학교 자료가 바뀌면 기억을 무효화하고, 새 조건이 들어간 질문은 다시 계산합니다. 전체 대화를 LLM에 보내 임의 맥락을 추론하는 메모리는 아닙니다. 규정과 진단·계획·일정을 함께 요청하면 필요한 분야를 순서대로 실행하고 결과를 합칩니다.

현재 Chroma 내부에는 SQLite 저장 파일이 있지만, 학생·성적을 영속 관리하는 별도 SQL DB는 없습니다. JSON·CSV 파일은 NoSQL DB가 아니며 MongoDB·Redis도 사용하지 않습니다. 현재의 가상 학생 실습에는 별도 DB를 추가하지 않고, 영속 학생 기록·공동 편집·공유 세션 같은 요구가 생길 때 재검토합니다. 구체적인 도입 조건은 위 의사결정 문서에 있습니다.

[복잡한 함수를 단계별로 읽는 자료](docs/SONARQUBE_코드읽기.md)는 학점 인정·계획·규정 근거·AI 응답·실행 기록의 역할별 함수를 요구사항과 테스트에 연결합니다. [SonarQube·커버리지 안내](docs/SONARQUBE.md)에서 별도의 로컬 분석 도구를 실행하고 실제 측정 결과를 읽는 방법을 확인하세요. 학습용 Red·Green 예제는 제품 코드의 복잡도·중복 지표와 구분합니다.

[테스트부터 읽는 TDD 학습 가이드](docs/TDD_학습가이드.md)에서 전체 기능의 요구사항 26개를 **기대 결과 → 실제 테스트 → 구현 함수 → 실행 결과** 순서로 공부할 수 있습니다. 새 학습 어댑터에는 같은 21개 검사를 사용하는 Red·Green·Refactor 실습이 있으며, 기존 앱의 과거 개발 이력을 TDD였다고 바꾸지는 않습니다. 프로젝트 폴더에서 `python scripts/tdd_study.py list`, `python scripts/tdd_study.py show REQ-008`, `python scripts/tdd_study.py replay` 순서로 시작하세요. API 키 없이 실행합니다.

[그림과 코드를 연결한 학습 가이드](docs/학습_가이드.md)는 역할·자료·학점 인정·졸업 판정·수강 계획·AI·일정을 실제 함수와 연결합니다. 대화 응답 아래 **실행 과정 살펴보기**에서 해당 질문이 통과한 단계, 함수 위치, 걸린 시간, 허용된 계산 요약을 확인할 수 있습니다. 이 로컬 기록은 별도 서비스 키 없이 사용할 수 있습니다.

LangChain은 공식 모델 통합 패키지인 `langchain-openai==1.7.2`·`langchain-anthropic==1.7.6`으로 **실제로 적용**했습니다. 상위 `langchain` 패키지는 설치하지 않았고 `langchain-core`의 모델·구조화 출력 계약을 사용합니다. LangGraph는 질문 유형별 실행 순서를 구성하고, LangSmith는 완료한 더미 실행을 관찰합니다. 세 도구의 책임과 테스트→코드 읽기 순서는 [개발도구 학습지도](docs/개발도구_학습지도.md)에 있습니다.

local 대화 모드에서 선택적으로 사이드바의 **LangSmith 학습 기록 · 선택**에 별도 LangSmith API 키를 입력한 뒤, **이 더미 실행을 LangSmith로 보내기**를 누르면 완료된 실행 기록을 전송합니다. **OpenAI API 키를 LangSmith 키로 사용할 수 없습니다.** 키 입력이나 질문 실행만으로는 전송하지 않습니다. 정확히 일치하는 내장 더미 사례만 허용하며, 이름·학번·성적표 원문·질문 원문·AI 자유문장·API 키는 기록에서 제외합니다. 자동 LangGraph 추적은 계속 끄고 허용한 단계·집계만 공식 LangSmith API에 보냅니다. 업로드 자료와 수정한 프로필은 외부 전송 대상에서 제외합니다. HTTP 응답은 실행 기록을 읽을 수 있지만 LangSmith 전송은 지원하지 않습니다. [연결과 기록 읽기](docs/LANGSMITH.md)

## 검증과 팀 전달

### 교수 수업자료와의 관계

제공된 **실습 ZIP9개와 이론 PDF10개 버전·351쪽**을 읽고 비교했습니다. Day4·Docker Day5는 단독본과 배포 ZIP 안의 내용이 달라 구분했습니다. [수업자료 반영 대조표](docs/수업자료_반영대조표.md)와 [실습 코드 비교보고서](docs/실습코드_비교보고서.md)에 원문 파일·함수·셀·페이지, 반영·변경·제외 이유를 적었습니다. 노트북 출력·키를 검증 근거로 쓰거나 수업 스크립트를 실행하지 않았습니다.

| 수업과의 주요 차이 | 현재 선택과 제한 |
|---|---|
| ReAct·반복 검색 | Add-on의 분기 워크플로우에 가까운 정해진 LangGraph 경로를 선택했습니다. 관찰 후 LLM이 다음 도구를 자율 선택하거나 재검색하는 루프는 없습니다. |
| 단기 메모리·혼합 질문 | 필요한 분야의 순차 실행·결과 합성, 최근4턴의 명시적 결과 재사용과 입력 변경 시 무효화를 추가했습니다. 전체 대화의 LLM 문맥 이해·영구 기억은 아닙니다. |
| FastAPI | `POST /chat`·세션 삭제와 공통 local/HTTP 클라이언트를 추가했습니다. HTTP는 AI off·키 전송 없음·실행 기록 열람만 지원합니다. |
| 임베딩·벡터DB·검색 | 수업의 Qdrant+BGE 대신 Chroma+로컬 다국어 MiniLM입니다. 토큰 한도·페이지 문맥 청킹을 사용합니다. 어휘 점수는 BM25가 아니며 가중 결합도 RRF가 아닙니다. 모델·DB 우열 비교는 하지 않았습니다. |
| SQL·NoSQL·Redis | 업무CRUD·영구 공동세션 요구가 없어 별도 도입하지 않았습니다. 수업 SQLite는 선택 심화이며, Chroma 내부 SQLite와 구별합니다. |
| Docker | app→api→MCP→Chroma 기본4서비스 구성과 정적 검증을 반영했습니다. 최신 새 이미지의 실제 기동은 환경 지연으로 남아 있습니다. |

공급자나 기술 수·커버리지 수치만으로 수업 코드보다 우수하다고 주장하지 않습니다. 이번 변경은 실패 기대값을 먼저 만들고 수정·재시험했으며, 과거 전체 개발 이력을 TDD로 바꾸지 않았습니다. [14장 발표 원고와 근거](docs/발표자료_작성안.md)는 실제 성과·한계와 교수 양식을 연결합니다. 발표 PPT는 공개 저장소의 [최종 결과 발표자료 14장](artifacts/jolup-presentation-20261026.pptx)입니다. 기존17장 기획안과 최종 결과 발표자료를 구분하고 팀원 역할 계획을 실제 작성 기여로 표시하지 않습니다. 팀원 파일의 로컬 통합은 자료 대기입니다.

[2026-10-23 종합 검토](docs/종합_검토_20261023.md)에서 요구사항별 완료·미검증·누락과 현재 작업 폴더가 과거 공유 ZIP·검증 기록과 다른 부분을 확인할 수 있습니다.

```bash
python -m pytest -q
JOLUP_TEST_VECTOR=1 python -m pytest tests/test_rag.py -q
python scripts/package_project.py --check

```

`data/samples/`에는 더미 CSV·프로필·독립 기대값 11종이 있습니다. 현재 재학 사례와 미래 졸업 시점의 경계 시험을 구분합니다. [ChatGPT 검증 프롬프트](docs/ChatGPT_검증프롬프트.txt)에는 첨부 자료, 사례별 프로필, 정답을 노출하지 않는 사용법, 수작업 채점표와 실제 시험 상태를 정리했습니다. 구현 후 수행한 인수시험을 과거의 ‘구현 전 통과’ 이력으로 바꾸지 않습니다.
